Installation prompt

Install the holylens-pcg-0.2.0-remote.zip file I provided: extract it, register it in my personal plugin marketplace, and install it. Keep the remote server https://service.holylens.com/mcp. No local Node.js setup is needed.

Supported recordings

WAV, MP3, RAW and PCM, up to 25 MB per file. RAW / PCM requires a known sample rate and mono signed 16-bit little-endian audio.

Do I need a local server?

No. The plugin connects to the HolyLens online service without Node.js. Upload links last 15 minutes; pending recordings are held temporarily in server memory.

Research use: analysis results are not a clinical diagnosis.
